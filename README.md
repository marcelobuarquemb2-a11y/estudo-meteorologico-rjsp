# Estudo Meteorológico RJ–SP

Coleta auditável de previsões meteorológicas para sete estações no litoral RJ–SP.

Horários de referência: 09h, 12h, 15h e 18h (America/Sao_Paulo). Horizontes: 24, 48 e 72 horas.

Fontes: Open-Meteo (ICON, GFS, ECMWF) e Meteoblue (basic-1h, wind-3h; identificação mLM ainda não comprovada).

**Status:** infraestrutura em implantação; não considerar dados coletados até validação dos arquivos e das fontes.
